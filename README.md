# mauricioaires30.github.io

Portfólio pessoal (HTML + CSS + JS puro), com tema claro/escuro e tradução PT/EN.

## Como editar
- **Textos, projetos, contatos, linguagens e chave Pix:** `js/i18n.js` (procure por `TODO`).
- **QR Code Pix:** salve a imagem em `assets/pix-qr.png`.
- **Imagens dos projetos:** coloque em `assets/` e troque o caminho em `SITE.projects`.
- **Visual/cores:** variáveis no topo de `css/style.css`.

## Rodar localmente
```
python -m http.server 8000
```
Abra http://localhost:8000.

## Deploy
GitHub Pages serve a branch `main` (raiz) em https://mauricioaires30.github.io.
